============================================================
Common Commands
============================================================

# Start frontend server
npm run dev

# Run all E2E tests (headless)
npm run e2e

# Run tests with browser visible
npm run e2e:headed

# Debug test (interactive inspector)
npm run e2e:debug

# View HTML report
npm run e2e:report

# Run specific test file
npx playwright test e2e/tests/usage-tracking-manual.spec.ts

# Run tests matching pattern
npx playwright test -k "should log"

File Purposes
============================================================

playwright.config.ts
  - Configures Playwright test runner
  - Sets base URL, browser, reporters
  - Enables tracing and screenshots

package.json (modified)
  - Added E2E test scripts
  - npm run e2e, e2e:headed, e2e:debug, e2e:report

  - 5 automated tests
  - Tests visibility, metrics, updates, API, progress bar

usage-tracking-manual.spec.ts
  - 4 interactive tests
  - Full API logging, structure validation, color verification

BillingPage.ts
  - Page Object Model
  - Encapsulates all UI interactions
  - Reusable across tests

api-logger.ts
  - API request/response logging
  - Filters, summaries, response times
  - Debugging aid
