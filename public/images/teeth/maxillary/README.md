## How to Convert Your SVG to PNG

If you have an SVG tooth image (e.g., from Figma or the design files):

1. Open the SVG in a browser or image editor
2. Export/save as PNG
3. Name the file `tooth-N.png` (where N is the tooth number)
4. Drop it in this folder — it will be used automatically

## Recommended Size

- Width: matches the tooth's display width (~44–54px at 1x, but any resolution works)
- Height: 141px (the SVG viewbox height for teeth)
- The images are stretched to fill the tooth area, so exact dimensions are flexible
